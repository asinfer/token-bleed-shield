## 💥 The Problem: Post-Mortem Dashboards Don't Save Money

Current AI cost monitoring tools are **reactive**. They give you sleek dashboards, charts, and alerts *after* the damage is done. By the time your billing webhook fires or your dashboard turns red:
- Your API keys are rate-limited.
- You have burned through $50-$200 in credits.
- Your model exhausted its context window and offloaded the original task objective.
- You didn't even get 25% through solving your actual problem.

### Why Do AI Agents Bleed Tokens?
1. **Agent Environment Wandering**:
   * *Example*: You don't use system Python; you strictly use [`uv`](https://github.com/astral-sh/uv). An autonomous agent without environment boundaries runs `which python`, `where python.exe`, traverses drives, checks system paths, and tests 10 different shell commands—burning thousands of tokens before writing a single line of code.
2. **MCP & Tool Schema Bloat**:
   * Rich tool schemas with verbose JSON specs and bloated docstrings consume 1,500–5,000 tokens **on every single LLM inference turn**.
3. **Context Churn & Core Idea Offloading**:
   * Huge stack traces, repeated log dumps, and entire multi-thousand-line files flood the context window, causing models to hallucinate or drop system instructions.
4. **Hallucination & Exploratory Death Loops**:
   * Models drifting into repetitive clarification cycles or tool exploration loops that compound token burn multiplicatively.
5. **The Economic Reality**:
   * Frontier reasoning models are compute-intensive. Without an architectural breakthrough, high-end inference will remain scarce and expensive. **Prevention is the only viable economic strategy.**

## ⚡ The Solution: The Preventive Workflow

**Token Bleed Shield** intervenes **before generation begins**.

```
                           THE PREVENTIVE PIPELINE
                          
┌─────────────────┐       ┌────────────────────────┐       ┌──────────────────────┐
│  User / Agent   │ ───►  │  1. Pre-flight Probe   │ ───►  │  2. Environment Lock │
│  Task Request   │       │  (Detect runtime once) │       │  (.agent-env.md)     │
└─────────────────┘       └────────────────────────┘       └──────────────────────┘
                                                                       │
                                                                       ▼
┌─────────────────┐       ┌────────────────────────┐       ┌──────────────────────┐
│  Dispatched to  │ ◄───  │ 4. Early Loop Breaker  │ ◄───  │ 3. Context & Schema  │
│  LLM Inference  │       │ (Preempt drift loops)  │       │    Gate / Minifier   │
└─────────────────┘       └────────────────────────┘       └──────────────────────┘
```

### 1. Pre-Flight Environment Pinning (`tbs probe`)
Detects your local stack once (e.g. `uv`, `pnpm`, `rustc`, `docker`, exact paths) and generates an immutable `.agent-env.md` system contract.
> Injects explicit rules: *"This system uses `uv run`. Do NOT explore system paths for python. Use `uv pip`, not `pip`."* Cuts hundreds of wasted reconnaissance tokens instantly.

### 2. Tool & Schema Minifier (`tbs lint-tools`)
Analyzes function calling and MCP schemas, strips docstring fluff, removes redundant JSON schema properties, and compresses tool definitions by up to **60%** without loss of tool accuracy.

### 3. Context Budget Gate (`tbs gate`)
Evaluates context payloads before dispatch. Identifies bloated file attachments, repetitive log dumps, and uncompressed ASTs, enforcing hard token boundaries before the API request leaves your machine.

### 4. Drift & Loop Circuit Breaker (`tbs breaker`)
Monitors agent tool-calling patterns in flight. If an agent calls the same directory search 3 times or repeats similar errors, the circuit breaker trips immediately before token waste compounds.

## 🛠️ CLI Usage

### 1. Probe & Lock Environment
Run once in your project root to generate the immutable agent runtime contract:

```bash
tbs probe --output .agent-env.md
```

Generated `.agent-env.md` snippet:
```markdown
# AGENT RUNTIME CONTRACT (Auto-generated by Token Bleed Shield)
- Package Manager: uv (DO NOT search for python or pip; use `uv run` and `uv add`)
- Node Package Manager: pnpm (DO NOT run `npm install`)
- OS: Windows (PowerShell 7)
- Working Directory: C:\Projects\demo
- Forbidden Actions: Do not traverse parent directories or search for system binaries.
```

### 2. Lint and Minify Tool Schemas
Inspect your MCP server or OpenAI/Anthropic tool schemas:

```bash
tbs lint-tools --input tools.json --output tools.min.json
```
Output:
```
✔ Inspected 14 tools
  Original token weight: 4,120 tokens
  Minified token weight: 1,650 tokens (-60.0% reduction)
  Saved ~2,470 tokens per LLM inference call!
```

### 3. Evaluate Context Budget Before Calling LLM
Pre-flight check a prompt or conversation history:

```bash
tbs gate --file context_payload.json --max-tokens 16000
```

### 4. Test Agent Tool Loops for Drift
Check agent execution histories for infinite loop patterns:

```bash
tbs breaker --history agent_log.jsonl
```

| Metric | Without Token Bleed Shield (Reactive) | With Token Bleed Shield (Preventive) |
|---|---|---|
| **Agent Behavior** | Wanders filesystem checking `python`, `python3`, `py`, `pip`, tests 8 wrong commands | Reads `.agent-env.md`, executes `uv run` on Turn 1 |
| **Tool Calls** | 12 unnecessary shell calls | 0 exploratory tool calls |
| **Token Cost** | ~14,500 tokens burned in recon | ~450 tokens locked contract |
| **Outcome** | Rate-limited or credit exhausted | Objective completed in 1st round |
